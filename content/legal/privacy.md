本ポリシーは、東京イベントカレンダー（以下「本サービス」）の利用にあたり、利用者の情報がどのように扱われるかを説明するものです。本サービスはオープンソースとして公開されており、ソースコードは [GitHub リポジトリ](https://github.com/illionillion/tokyo-event-calendar) で確認できます。

## 1. アカウントとプロフィール

本サービスにはアカウント機能はありません。利用者のプロフィール情報を収集・保存することはありません。

## 2. 検索条件（URL）の取り扱い

日付、エリア、開催形態、キーワードなどの検索条件は、ブラウザの URL（クエリパラメータ）として扱います。これらの条件は本サービスのサーバー上に利用者アカウントと紐づけて保存するものではありません。

## 3. イベント情報と画像

本サービスが表示するイベント情報は、[connpass](https://connpass.com/) の API から 1 日 1 回取得したものです。対象の基本は、東京都・神奈川県・埼玉県・千葉県で開催されるイベントです。この検索に載らないイベントのうち、申請を確認したものも同じ取得に含めます。利用者のアクセスごとに connpass API を呼び出すことはありません。イベントカードを開くと、connpass のイベントページへ移動します。

終了から 7 日を超えて経過したイベントは、保存しているスナップショットとサイト上の表示の両方から除きます。終了時刻が無い場合は、開始時刻を終了時刻として同じ基準で除きます。

取得したイベント情報のうち、主催者のニックネーム・表示名などの connpass ユーザーに関する情報は保存しません。参加者の情報は取得しません。

イベント画像は、取得した `image_url` がある場合にカードへ表示します。この URL は connpass 側である程度の時間で失効するため、表示できないことがあります。`image_url` が無いイベントは、タイトルの頭文字を表示します。

毎日、次の土曜の紹介が案内する来週（日曜から土曜まで、キーワード「LT」と「もくもく」）のイベントを選び、短い紹介動画を作り直して、同じ URL で公開します。動画を作るとき、その時点で取得できた `image_url` の画像は動画ファイルの中に埋め込みます。取得できない、または URL が無い場合、そのカードは文字だけです。

## 4. アクセス解析・広告

Cookieを使わないアクセス解析（Cloudflare Web Analytics）を利用しています。広告タグは設置していません。

## 5. お問い合わせ

本サービスに関するお問い合わせ・不具合報告は [GitHub Issues](https://github.com/illionillion/tokyo-event-calendar/issues) をご利用ください。GitHub 側の利用規約およびプライバシー方針が適用されます。

表示されないイベントの申請は、同じ GitHub Issues、または [作者への DM（X）](https://x.com/Sei_engineer) で受け付けます。DM の内容は本サービスには保存しません。X 側の利用規約およびプライバシー方針が適用されます。

## 6. 本ポリシーの変更

法令の改正やサービス内容の変更に応じて、本ポリシーを更新することがあります。更新後の内容は本ページに掲載した時点から効力を有するものとします。
